# Retired Button Modes

Classic and Mayhem are not part of Button V2. Shared protocol types expose only
the playable `V2` mode. The server has no handlers, state, scoring or controls
for Action Tokens, secret actions, public Mayhem events, DOUBLE, BLOCK, PROTECT,
global recharge, previous-actor lock or the former exact-20 press game.

Do not reintroduce these concepts as aliases or compatibility paths. Any future
mode requires explicit product authorization and must preserve the same
authoritative owner, validated intentions and recipient-private projection rules.
